# Deployment guide location

The current English guide is [Running the existing ArchCert application](DEPLOYMENT.md).
The [README](../../README.md) contains the first-use instructions. There is no
separate local application or API. [ADR 0071](../adr/0071-product-account-integration.md)
supersedes the separate-service interpretation in ADR 0070. Historical runs remain
bound to their exact committed sources and are not acceptance of the integrated API.
